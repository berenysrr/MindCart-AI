# 🌌 MindCart AI Nedir?

**MindCart AI**, kullanıcıları dijital pazaryerlerindeki:

- 🎭 Sahte yorumlardan  
- 🧠 Psikolojik manipülasyonlardan  
- 💸 Sahte indirimlerden  
- ⚠️ Dark Pattern tasarımlarından  
- 📈 Şişirilmiş fiyatlardan  
- ⏳ Yapay aciliyet baskılarından  

korumak amacıyla geliştirilen futuristik bir **AI Destekli Alışveriş Karar Koruma Platformudur.**

Günümüz e-ticaret sistemlerinde kullanıcılar; algoritmalar, manipülatif kampanyalar ve psikolojik satın alma baskılarıyla yönlendirilmektedir.

MindCart AI, tüm bu riskleri gerçek zamanlı analiz ederek kullanıcıların:

✔ Daha bilinçli  
✔ Daha rasyonel  
✔ Daha güvenli  

alışveriş kararları vermesine yardımcı olur.

---

# 🚀 Temel Özellikler

## 🛡️ AI Cooldown Protection
Riskli veya dürtüsel satın alma kararlarını otomatik olarak algılar ve kullanıcıyı **24 saatlik düşünme sürecine** yönlendirir.

### Sağladıkları:
- Acele satın alma baskısını kırar
- Duygusal harcamaları azaltır
- Kullanıcıyı yeniden düşünmeye teşvik eder
- Finansal farkındalık oluşturur

---

## 🔍 MindCart Scan Engine
Ürün linkleri ve alışveriş sepetleri üzerinde gelişmiş AI tabanlı risk analizi gerçekleştirir.

### Analiz Edilen Riskler:
- Sahte yorumlar
- Bot aktiviteleri
- Manipülatif satış teknikleri
- Yapay stok baskıları
- Fiyat şişirme taktikleri
- Influencer manipülasyonları

---

## ⚡ Neon Risk Chips Sistemi

Dinamik ve gerçek zamanlı risk görselleştirme sistemi.

| Risk Türü | Açıklama |
|---|---|
| 💬 Sahte Yorum | Bot veya manipülatif yorum tespiti |
| ⚠️ Manipülasyon | “Son 3 ürün kaldı” gibi baskı teknikleri |
| 🏷️ Fake İndirim | Yapay fiyat yükseltme & sahte kampanya |
| ⚡ Dürtüsel Risk | Kullanıcının anlık satın alma baskısı |

---

## 🧠 Karar Geçmişi Sistemi
Daha önce analiz edilen ürünleri ve AI karar önerilerini saklar.

### Özellikler:
- Geçmiş analiz görüntüleme
- Risk skoru takibi
- Karar karşılaştırma sistemi
- Kullanıcı alışveriş farkındalığı

# 🚀 Kurulum

## 📋 Gereksinimler

- Node.js v16+
- .NET SDK v7/v8
- Git

---

## 1️⃣ Repoyu Klonlayın

```bash
git clone https://github.com/berenysrr/MindCart-AI.git
cd MindCart-AI
```

---

## 2️⃣ Frontend Kurulumu

```bash
cd client
npm install
npm run dev
```

---

## 3️⃣ Backend Kurulumu

```bash
cd server
dotnet restore
dotnet run
```
